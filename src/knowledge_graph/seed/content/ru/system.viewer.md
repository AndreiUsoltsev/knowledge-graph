# Просмотрщик графа

```powershell
knowledge-graph gui
knowledge-graph gui --port 8766 --no-browser
knowledge-graph --lang ru gui
```

`serve` — совместимый псевдоним. Адрес по умолчанию `http://127.0.0.1:8765/`, сервер слушает только локальный интерфейс. Ctrl+C останавливает его. HTML, CSS и JavaScript входят в пакет и работают вне каталога исходников.

Выберите узел из списка или графа, читайте документ и переходите по пояснениям. Поиск использует выбранный язык. Назад и вперёд используют историю браузера. Копирование ID даёт идентификатор для `node ID`. Фильтруйте типы узлов и связей; выбирайте ограниченную глубину окружения или весь граф. Колесо и кнопки меняют масштаб, перетаскивание перемещает граф, «Вместить» центрирует его. Размеры холста и SVG ограничены при изменении окна.

Первое открытие использует EN независимо от языка системы. EN/RU сохраняет выбор в браузере, выбранный узел и настройки графа. Явный `--lang ru gui` открывает русский. Узлы без перевода сохраняют исходный текст; внешних сервисов перевода нет.

Markdown создаётся безопасными DOM-элементами, HTML остаётся текстом. Активны только известные ссылки графа и HTTP/HTTPS. Сервер предоставляет чтение API и фиксированных ресурсов, не произвольных файлов. Редактируйте текстовым редактором и обновляйте после проверки.
