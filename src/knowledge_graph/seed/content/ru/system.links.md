# Смысл связей

Связь направлена от источника к цели. Пояснение сообщает, зачем и когда переходить. Направление сохраняет смысл, хотя просмотрщик показывает входящие и исходящие связи.

| Тип | Значение |
| --- | --- |
| contains | Источник объединяет целевые темы |
| explains | Источник объясняет цель |
| requires | Для понимания источника требуется цель |
| related | Темы полезно изучать вместе |

Пишите конкретные пояснения: «Изучите обязательные поля перед добавлением документа». Не повторяйте только название цели. `requires` — предпосылка, а не следующий шаг во времени.

`neighbors ID --direction out` показывает переходы от источника к цели, `--direction in` — документы, ссылающиеся сюда. По умолчанию `both`. `walk` и `path` поддерживают фильтры направления и типа, сохраняя направление исходных связей. Циклы допустимы, обход отслеживает посещённые ID.
