# Формат базы

`graph.json` использует версию 1 и содержит `version`, непустой `entry_points`, списки `nodes` и `edges`. Документы — UTF-8 Markdown внутри базы. ID остаются неизменными при переименовании и переводе.

Узел содержит `id`, `title`, `type`, `summary`, `tags`, `content`. ID начинается со строчной латинской буквы или цифры и состоит из строчных латинских букв, цифр, точек, подчёркиваний и дефисов. Типы: `system`, `concept`, `workflow`, `tool`, `reference`. Заголовки, описания и документы непустые; теги — список непустых строк. Точки входа уникальны и ссылаются на существующие ID.

Связь содержит `source`, `target`, `type`, `label`. Оба узла существуют; повтор тройки источник/цель/тип запрещён. Типы: `contains`, `explains`, `requires`, `related`. Изучите [смысл связей](kg:system.links).

`content` — относительный путь к `.md` внутри базы. Абсолютные пути, выход через `..` и символические ссылки наружу запрещены. Проверка читает каждый документ.

Основные поля английские. Необязательный `translations.ru` узла содержит `title`, `summary`, `tags`, `content`; у связи — `label`. Русские Markdown хранятся отдельно. Без перевода используются исходные поля. ID, типы и ключи JSON остаются прежними. Проверяются оба языка независимо от языка чтения.

```json
{"source":"topic.overview","target":"topic.format","type":"contains","label":"Read before editing.","translations":{"ru":{"label":"Прочитайте перед изменением."}}}
```
