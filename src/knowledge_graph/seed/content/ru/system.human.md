# Работа человека

`knowledge-graph gui` открывает чтение, поиск и переходы в браузере. Просмотрщик доступен только для чтения; редактируйте документы текстовым редактором.

1. Выберите уникальный постоянный ID и конкретную тему.
2. Напишите UTF-8 Markdown в `content/`.
3. Добавьте обязательные поля в `graph.json` с относительным путём.
4. Соедините полезные узлы типизированными связями с пояснениями. Точку входа добавляйте для подходящего начального документа.
5. При необходимости добавьте полный `translations.ru` и отдельный русский документ.
6. Выполните `knowledge-graph validate`, исправьте ошибки и проверьте предупреждения о недостижимых узлах.
7. Обновите просмотрщик и проверьте переходы. При необходимости храните базу в Git проекта.

Не переиспользуйте ID для другой темы. При удалении исправьте связи и точки входа. Предпочитайте короткие документы и переходы вместо дублирования. Прочитайте [формат](kg:system.format) и [проверку](kg:system.validation). Установка изменяет только новую `.knowledge-graph`, не остальные файлы и настройки Git.
