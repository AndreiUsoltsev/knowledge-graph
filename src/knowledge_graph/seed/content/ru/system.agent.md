# Работа ИИ-агента

Изучайте документацию постепенно. CLI возвращает JSON, полный Markdown находится в `body`. Успех содержит `success` и `data`; ошибка — стабильный `code`, сообщение и подробности.

1. Выполните `knowledge-graph entry` или `knowledge-graph --lang ru search "тема вопроса"`.
2. Прочитайте лучший документ: `knowledge-graph --lang ru node ID`.
3. Изучите `knowledge-graph --lang ru neighbors ID`; выберите связь по типу, направлению и пояснению.
4. Загружайте следующий документ, когда он полезен.
5. Используйте `walk ID --depth 2 --max-nodes 20` для ограниченной карты или `path START END` для кратчайшего маршрута.

Поиск требует всех слов и отдаёт приоритет ID и заголовкам. По умолчанию английский; `--lang ru` выбирает русский. Без перевода используется исходный документ. Вне проекта задавайте `--db PATH`. При отсутствии базы запустите `install DIR`, при повреждении изучите `validate` и исправьте ошибки.

Сверяйте знания с реальными источниками. Обновляйте документы и связи при изменении поведения. Инициализация базы не меняет инструкции агента. Отдельная команда `knowledge-graph agents install --target all` устанавливает постоянные правила и подробный skill; `knowledge-graph agents doctor --target all` проверяет готовность. После установки перезапустите сессию агента. Содержимое существующей базы сохраняется.
