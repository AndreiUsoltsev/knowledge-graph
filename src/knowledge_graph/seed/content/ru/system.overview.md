# Система документации

Граф знаний объединяет небольшие Markdown-документы в узлы. Типы и пояснения связей помогают человеку или ИИ выбрать следующий полезный документ, не загружая всю базу.

Начальная база описывает только эту систему. Знания о вашем проекте добавляйте отдельно. Инструмент подходит любому проекту, требует Python 3.10 или новее и использует стандартную библиотеку.

`knowledge-graph install DIR` создаёт базу без перезаписи существующей `.knowledge-graph`. Без `--db` команды ищут ближайшую базу выше текущего каталога; `--db PATH` задаёт точный каталог.

Начните с `entry`, `search "тема"`, `node ID`, `neighbors ID` или `gui`. Для русского чтения задавайте `--lang ru` перед командой. Изучите [формат](kg:system.format), [связи](kg:system.links), [работу агента](kg:system.agent) и [работу человека](kg:system.human). Проверяйте базу после изменений и сверяйте знания с реальными источниками.
